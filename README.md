# Flask Notes App

A simple Flask-based Notes web application with login, register, add, edit, and delete features.

## 🔗 Live Demo
👉 https://098raj.pythonanywhere.com

## 🚀 Features
- User Authentication (Login/Register)
- Add, Edit, Delete Notes
- Clean Dashboard UI
- SQLite Database

## 🛠 Tech Stack
- Python
- Flask
- HTML, CSS
- SQLite
- Git & GitHub
